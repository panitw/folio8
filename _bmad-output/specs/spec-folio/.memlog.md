Explicitly supersedes addendum.md C.
- (decision) FILE UNITS: coordinates, sizes, margins and font sizes are PDF POINTS written as JSON numbers with at most three decimal places — exactly one millipoint, so conversion to the engine's internal int64 millipoints (AD-2) is an exact x1000 with no rounding. More than three decimals is a load error because it cannot be represented exactly. Points over raw millipoints because a hand-editor writes x:36, not x:36000.
- (decision) FONT CHAINS ARE NAMED: the template declares fonts as named ordered fallback chains and style.fontFamily references a KEY of that object, never a face name. Declares a chain once, reuses it, and keeps the chain part of the render identity per AD-8.
- (decision) A table declares x and y but NEITHER width NOR height — width is the sum of column widths (AD-13), height is whatever the data produces. Storing either would let the designer and the engine disagree. Table columns carry their own ids from the same counter so a diagnostic can name a column.
- (decision) {{page}} and {{pages}} are format-level late-bound slots, NOT expressions and NOT a data namespace — the only values in the format depending on pagination (AD-4). Closes the loop with AD-4's rule that no page namespace exists for expressions to reach.
- (decision) Style defaults fixed, which also closes readiness finding C3's table-border ambiguity: fontSize 10, align left, valign top, padding 0, border absent by default and 0.5pt #000000 on all four edges when present, background transparent. Colours are #RRGGBB and there is no colour-by-data.

- (change) 2026-09-19: The '~9 MB first load is accepted' constraint is superseded. Measured at release 3e4b8b52 (app 1.0.0) the blocking first load is 80 assets / 18.63 MiB over the wire — the figure had aged past 2x unwatched, mostly via the CJK font (4.72 MiB) and the catalogue growing 21 -> 31 faces (3.01 MiB). spec-deferred-offline-cache splits the release into a guaranteed core tier (28 assets / 10.67 MiB) that gates the designer and a deferred tier (52 assets / 7.97 MiB) fetched on first use, so the accepted first load becomes ~10.67 MiB and 'genuinely offline' becomes a per-asset claim rather than a whole-release one. CAP-10's success criterion is unchanged in substance — the designer still previews with the network disconnected after first load — but now holds over what this browser has actually fetched.
